# みやぎ自治体クイズ

質問への回答をもとに、宮城県内の自治体・行政区を推定するブラウザゲームです。スマートフォンのブラウザでも利用できます。

## ゲームの種類

- [現行版（仙台市5区を含む39地域）](./index.html) — v2.6／154問
- [旧市町村版（74市町村）](./old/index.html) — v1.6／235問

現行版では、宮城県内の35市町村のうち仙台市を5つの区に分け、計39地域を候補とします。

旧市町村版は、**宮城県全域で1987年10月31日（昭和62年）の74市町村**を対象とします。市町村の区域・鉄道・施設の基準日をすべて1987年10月31日に統一しています。後年開業の施設や現在の区分に依存する質問は除外または当時存在した史跡・施設に差替えています。全質問の地理的帰属についての独立全数照合はなお必要です。

## 利用方法

各版の `index.html` をブラウザで開くと遊べます。回答が難しい質問には「分からない」を選べます。ゲームは位置情報・住所の入力を必要としません。

## 収録内容と注意点

地域データと質問は確認・改訂を続けています。曖昧な地形表現の削除に加え、全質問の区域・時点・対象条件の記述を明確化しています。回答結果は参考とし、自治体の公式な区分や所在地の証明には使用しないでください。

## 公開方法

GitHub Pagesを使う場合、ルートの `index.html` が現行版、`old/index.html` が旧市町村版です。公開の有無はリポジトリの **Settings → Pages** で管理してください。

## 1987年版の確認状況

- 判定区域、鉄道・施設の時点：1987年10月31日
- 質問の取捨・年代修正の記録：[`docs/1987-question-audit.md`](./docs/1987-question-audit.md)
- 後年開業施設・新しい地域区分を使う設問は除外しました。個々の施設の所在や1987年時点の利用状況には追加照合を要する項目が残ります。
